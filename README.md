# Chess Teacher App

AI-powered chess teaching app with interactive lessons, daily tasks, progress tracking, and a virtual chess teacher.

## Features (planned)
- Interactive chessboard with full move validation
- AI Chess Teacher that explains moves and teaches concepts
- Structured lessons (beginner → advanced)
- Daily puzzles & tasks with streaks
- Progress tracking & stats
- Play against the computer or practice modes

## Tech Stack
- **Next.js 15** (App Router)
- **TypeScript**
- **chess.js** – chess logic & validation
- **react-chessboard** – beautiful interactive board
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Project Structure
```
src/
  app/           # Next.js App Router pages
  components/    # UI components (ChessBoard, Teacher, etc.)
  lib/           # chess helpers, lesson data, etc.
  types/         # TypeScript types
```
